# Problem statement alignment

Every phrase of the brief, mapped to what Nukkad does. "Partial" items are called out honestly.

| Brief says | Nukkad delivers | Status |
|---|---|---|
| **Hyperlocal** | Pick your city or use your location; in-person events within 10 to 100 km are pinned on top with distance and a Google Map | Done |
| **Event Discovery** | One search box over title, host, domain, city, state and country, plus filters for domain, online or in person, type, date, fee and registration deadline | Done |
| **Community Engagement** | Per-event doubts community (questions and replies), WhatsApp community link, follow hosts, invite a friend, weekly stamp trail | Done |
| **Domain: Software Development** | Full-stack app with tests, plus 16 domains from software dev to cyber security and blockchain | Done |
| **Hackathons, workshops, meetups, conferences, summits** | Required event type with exactly these five | Done |
| **Colleges, startups, companies, communities** | Required "hosted by" with exactly these four | Done |
| **Scattered across WhatsApp, Instagram, LinkedIn, posters, websites** | One page per event: poster, description, dates, fee, rules, FAQs, contact, registration link, community, and optional Instagram and LinkedIn. Paste a WhatsApp or Instagram message to auto-fill. | Done (paste-based; no scraping) |
| **People miss events relevant to them** | "Suggested for you" from profile interests and events you joined, with the reason; deadline-closing filter; calendar reminders (even for deadline-only events) | Partial: no push notifications yet |
| **Organizers struggle to reach the right audience nearby** | Audience finder: in-person events count people nearby, online events count people anywhere; optional share kit | Done (sample profiles until real sign-ups) |
| **Discover relevant events near them** | Nearby pinned first, then everything else searchable, including other states, countries and online | Done |
| **Reach and engage their target audience** | Audience finder, going counts, follow, doubts community, contact email | Done |
| **More people actually attend** | RSVP, going counts, calendar, invite a friend, registration deadline shown on every card | Partial: attendance is not verified on the day |
| **Return to the community** | Stamp trail, follow host, history-based suggestions | Partial: stamps count RSVPs, not check-ins |
| **User-friendly** | Four pages; posting is one page in five sections; dates, venue and map hide when not needed; accessible forms | Done |
| **Location-aware** | Geolocation or city, distance, Google Map, directions; online events have no distance | Done |
| **Interest-based** | 16 domains in profile and on every event | Done |
| **Personalized** | Name greeting, match %, suggestions from interests and past events, followed hosts boosted | Done |
| **Easy event posting** | Required: title, host, type, domain, description, mode, date or deadline, contact. Everything else optional. | Done |
| **Find relevant events quickly** | Search plus filters; suggestions on top | Done |
| **Improve visibility for organizers** | Shared persistent feed, audience finder, optional share kit, spam screening | Done |
| **Higher participation and repeat engagement** | RSVP, reminders, invites, doubts community, streak stamps | Done (see partials) |
